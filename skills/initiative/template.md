# Initiative template

The standardized format for every initiative `/adlc:initiative` produces. The
skill fills this skeleton from the dialogue; it never invents sections beyond
these.

## Name

Outcome-phrased, 2–5 words, a **state** not an activity:

- ✅ `Coach-ready`, `Trustworthy data`, `Zero-friction logging`
- ❌ `Improve coach features`, `Work on data quality`

## Description

```markdown
> <One-sentence outcome statement — what is true when this initiative is complete.>

## Why now

<The motivation: what hurts today, what this unlocks, why this beats waiting.>

## Success criteria

- <Observable check #1 — something you could verify true or false>
- <Observable check #2>
- <…>
```

Rules:

- The blockquote opener is the glanceable one-liner — the same convention as an
  adlc card's preamble, one level up.
- Success criteria are observable checks, not vibes — they are what initiative
  health updates report against, and what makes "is this done?" answerable.
- **No Contributing-projects section.** Linear renders attached projects
  natively on the initiative; enumerating chunks belongs to the downstream PRD
  stage, not here.
