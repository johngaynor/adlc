# Specs

Phased specs for non-trivial work, one file per task, named
`{YYYY-MM-DD}-{kebab-title}.md` (e.g. `2026-08-03-linear-init-integration.md`).

This directory is **archival**: the files here predate the lifecycle's move to
Linear and are kept for history. Canonical specs and plans for in-flight work
live on the task's Linear issue (METHODOLOGY.md idea 4).
